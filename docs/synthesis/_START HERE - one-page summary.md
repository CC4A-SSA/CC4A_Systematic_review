# Start here — one-page summary

**What you're doing:** building the evidence that feeds the Activity 2 geospatial engine. For each carbon-crediting practice: how much it raises yield in a normal year, how much loss it avoids when drought, heat or flood hits, what it costs, and how widely it's already adopted.

**What it is not:** a literature review that ends in a report. Every number goes into one of five tables the pipeline reads — practice recipes, the loss matrix, a cost table (shared with Chun), an adoption table, and a register of long-term datasets. If a number doesn't land in one of those, don't extract it.

**How:** AI does the volume — searching, screening, extracting with a quote and page reference for every number, and a separate AI pass that checks each quote exists and actually says what's claimed. You do the judgement: setting up each practice, resolving disagreements, and deciding mechanism, confidence and what to do when evidence is thin. Thin evidence is a finding; record it, don't pad it.

**The three rules that matter most**

1. Get treatment and control yields **separately for bad and normal seasons**, with site coordinates and dates. That's what lets us calculate avoided loss.
2. **Every number has a verbatim quote and locator.** No exceptions except values taken from ERA.
3. **Keep negative and null results.** A practice that fails under drought is exactly what we need to know.
